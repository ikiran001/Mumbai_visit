# My First Visit to Mumbai

A beautiful, responsive HTML travel journal website documenting a first trip to Mumbai — famous landmarks, luxury resorts, personal experiences, photo gallery, and travel tips.

## Live Preview

Open `index.html` in any browser, or use a local server:

```bash
# Python
python3 -m http.server 8080

# Node
npx serve .
```

Then visit http://localhost:8080

## What's Inside

- **Hero** — Stunning Gateway of India backdrop
- **Famous Places** — Gateway of India, Marine Drive, Taj Palace, Sea Link, Elephanta, Juhu, CSMT, Haji Ali
- **Resorts** — Taj Mahal Palace, ITC Maratha, JW Marriott Juhu, St. Regis, The Resort Mumbai
- **My Experience** — Day-by-day travel journal timeline
- **Photo Gallery** — Curated Mumbai snapshots
- **Street Food** — Vada pav, pav bhaji, bhel puri and more
- **Travel Tips** — Practical advice for first-time visitors

## Tech

- Pure HTML, CSS, JavaScript — no frameworks
- Responsive design (mobile, tablet, desktop)
- Scroll animations & smooth navigation
- Images from [Unsplash](https://unsplash.com)
