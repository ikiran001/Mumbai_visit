# My First Visit to Mumbai

A beautiful, responsive **React + Vite** travel journal website documenting a first trip to Mumbai.

## Quick Start

```bash
npm install
npm run dev
```

Open **http://localhost:5173**

## Tech Stack

- React 18
- Vite 5
- Pure CSS (no UI framework)

## Build

```bash
npm run build        # production build → dist/
npm run preview      # preview production build
```

For GitHub Pages:

```bash
GITHUB_PAGES=true npm run build
```

## What's Inside

- Famous Places (Gateway of India, Marine Drive, Taj Palace, etc.)
- Resorts & Hotels with descriptions
- Day-by-day travel journal
- Photo gallery, street food, travel tips
